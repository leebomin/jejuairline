# 팀 공유 — 매뉴얼 대비 우리 결과 비교

작성일: 2026-06-26

---

## 핵심 요약

매뉴얼이 제시한 목표 대비 일부 항목은 달성했지만
주요 지표에서는 아직 격차가 있습니다.

---

## 1. RMSE 목표 달성 여부

매뉴얼 목표: **RMSE ≤ 9.08**

| 조건 | 매뉴얼 제시 성능 | 우리 결과 | 달성 여부 |
|-----|--------------|---------|---------|
| 장거리 (엔진 충분) | 10.38 (Alomari 기준) | **9.57** | ✅ 목표 초과 달성 |
| 단거리 LCC 보정 후 | ~7.33 (논문 기준) | **12.02** | ❌ 4.7pt 차이 |
| 단거리 보정 없음 | ~15.97 | **14.99** | ✅ 약간 개선 |
| 중거리 | 미제시 | **12.81** | 비교 불가 |

**장거리는 매뉴얼보다 오히려 좋게 나왔어요.**
단거리가 문제예요. 매뉴얼은 7.33을 달성했는데 우리는 12.02예요.

---

## 2. LCC 보정 효과 차이

매뉴얼: LCC 라벨 20% 사용 시 RMSE **30.8% 개선**

우리 결과:
```
DS01 단거리: 14.32 → 12.76  (10.8% 개선)
DS03 단거리: 14.99 → 12.02  (19.8% 개선)
평균: 약 15.3% 개선
```

매뉴얼의 절반 수준이에요.

**왜 차이가 날까요?**
매뉴얼의 LCC 보정은 Medium+Long으로 먼저 학습하고
Short 데이터만 따로 fine-tuning하는 방식이에요.
우리는 전체 데이터에 가중치만 줬어요.
방식이 달라서 효과도 차이가 납니다.

---

## 3. 모델 안정성 차이

매뉴얼: seed 3개 반복 시 RMSE 편차 **±0.98**

우리 결과:
```
앙상블 폴드 편차: 평균 ±4.2
CNN-LSTM 폴드 편차: 평균 ±9.8
```

매뉴얼보다 훨씬 불안정해요.
이유는 엔진 수가 2~3개뿐이라 교차검증 폴드마다 결과가 크게 달려요.
매뉴얼은 더 많은 엔진 데이터를 썼을 가능성이 높아요.

---

## 4. 완료하지 못한 단계

매뉴얼은 3단계 구조예요:

```
Stage 1: Feature Selection + 앙상블/CNN-LSTM  ← 완료
Stage 2: Few-shot Fine-tuning (LCC 보정)      ← 부분 완료 (방식이 다름)
Stage 3: Knowledge Distillation (21→8센서)    ← 미완료
```

Stage 3을 완료해야 실제 비행기에 달 수 있는 경량 모델이 나와요.

---

## 5. 검증 항목 달성 여부

| 검증 항목 | 매뉴얼 목표 | 우리 결과 |
|----------|-----------|---------|
| N-CMAPSS RMSE | ≤ 9.08 | 9.57 (장거리만) / 12.02 (단거리) |
| DASHlink FPR | ≤ 15% | 미측정 |
| NGAFID F1 | ≥ 0.80 | 미측정 |

DASHlink와 NGAFID 검증을 아직 못 했어요.
이 두 가지가 실제 비행기 적용 가능성을 보여주는 핵심 검증이에요.

---

## 6. 팀원에게 묻고 싶은 것

1. **Stage 2 방식이 다른 것 같은데 확인해주실 수 있나요?**
   매뉴얼은 Medium+Long으로만 먼저 학습 후 Short으로 fine-tuning하는데,
   우리는 전체 데이터에 가중치를 줬어요.
   방식을 맞추면 LCC 보정 효과가 매뉴얼(30%)에 가까워질 수 있을 것 같아요.

2. **DASHlink, NGAFID 검증 어떻게 진행할 건가요?**
   FPR ≤ 15%, F1 ≥ 0.80 달성 여부를 확인해야
   PoC가 완성됩니다.

3. **Stage 3 Knowledge Distillation 일정이 어떻게 되나요?**
   21개 센서 → 8개 공통 센서 경량화가 완료돼야
   실제 비행기에 붙일 수 있는 모델이 나와요.
