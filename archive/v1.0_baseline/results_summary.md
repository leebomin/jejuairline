## 2. 핵심 발견

### 발견 1 — LCC 보정이 단거리에서 유효함
```
DS01 단거리: 14.32 → 12.76  (10.2% 개선)
DS03 단거리: 14.99 → 12.02  (19.8% 개선)
평균 약 15% 개선
```
소량의 단거리 데이터에 5배 가중치를 주는 few-shot fine-tuning이
실제로 효과가 있음을 확인함.

### 발견 2 — CNN-LSTM은 엔진 수가 충분해야 함
```
엔진 6개 (DS02 장거리): CNN-LSTM 9.57  앙상블 11.27 → CNN-LSTM 승
엔진 2개 (DS01):        폴드별 편차 최대 17.2pt → 신뢰 불가
엔진 3개 (DS03 단거리): 폴드 9.8 / 26.3 / 9.0 → 26.3이 이상값
```
CNN-LSTM은 데이터가 충분할 때 강력하지만,
엔진 수가 적으면 특정 엔진에 과적합되어 불안정함.

### 발견 3 — 앙상블이 전반적으로 안정적
```
앙상블 폴드 편차 평균: 4.2pt
CNN-LSTM 폴드 편차 평균: 9.8pt
```
어느 데이터셋에서도 극단적 실패 없음.
실제 현장 적용에는 안정성이 중요하므로 앙상블이 더 실용적.

### 발견 4 — 장거리가 가장 예측하기 쉬움
```
DS02 장거리:  9.57 (CNN-LSTM 기준 전체 최고)
DS03 장거리: 11.23 (앙상블 기준 전체 최고)
```
장거리 비행은 패턴이 일정해서 AI가 학습하기 쉬움.
단거리는 짧은 사이클이 반복되어 노화 패턴 파악이 어려움.

## 3. 최종 모델 설계 권고

### 3-1. 비행 클래스별 권장 모델

| 비행 클래스 | 권장 모델 | 이유 |
|------------|----------|------|
| 단거리 (LCC) | LCC 보정 앙상블 | 15% 개선 확인, 안정적 |
| 중거리 | 앙상블 | CNN-LSTM 폴드 편차 큼 |
| 장거리 | CNN-LSTM (엔진 충분 시) / 앙상블 | 엔진 6개 이상이면 CNN-LSTM 우세 |

### 3-2. 최종 모델 구조

```
입력: 센서 데이터 (WINDOW=50개 묶음)
         ↓
[비행 클래스 판별]
         ↓
단거리 → LCC 보정 앙상블 (GBM + RF + MLP, 가중치 5배)
중거리 → 앙상블 (GBM + RF + MLP)
장거리 → 엔진 수에 따라 분기
           엔진 6개 이상 → CNN-LSTM 3층
           엔진 6개 미만 → 앙상블
         ↓
출력: RUL (잔여 수명 예측값)
```

### 3-3. 기대 성능

| 비행 클래스 | 예상 RMSE | 기준 |
|------------|----------|------|
| 단거리 | ~12.4 | DS01/DS03 LCC보정 평균 |
| 중거리 | ~14.9 | DS01/DS03 앙상블 평균 |
| 장거리 | ~10.7 | DS02/DS03 앙상블 평균 |

## 4. 개선 여지

### 즉시 시도 가능한 것
- WINDOW를 60~70으로 더 늘려보기 (실험 B에서 50이 최적이었지만 더 클 수 있음)
- LCC 가중치를 7~8배로 올려보기 (5배에서 수렴했지만 단거리 데이터 많으면 다를 수 있음)
- CNN-LSTM 에폭을 20→50으로 늘려보기 (더 충분히 학습)

### 데이터가 더 필요한 것
- 실제 제주항공 운항 데이터 확보 → LCC 보정 효과 재검증
- 엔진 수가 10개 이상인 데이터셋에서 CNN-LSTM 재실험

### 논문과의 비교
- 매뉴얼 목표 RMSE: 9.08 이하
- 현재 최고 성능: 9.57 (DS02 장거리 CNN-LSTM)
- 단거리 기준: 12.02 → 목표까지 약 3pt 차이

## 5. 결론

LCC 보정 앙상블을 주 모델로 채택하되,
엔진 수가 충분한 장거리 노선에는 CNN-LSTM을 병행 운용하는
하이브리드 구조가 가장 현실적인 최종 모델임.
