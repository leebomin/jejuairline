# 최종본 (v3)

시뮬레이션 기반 잔여수명 예측(모델 1)과 실비행 기반 정비진단(모델 2)을 각각 학습하고, 정비 결정 단계에서 결합한 최종 제출본입니다. 프로젝트 전체 개요는 [저장소 README](../README.md), 설계와 결과의 상세는 [기술문서](technical_report.md)를 참고하세요.

## 구성

| 경로 | 내용 |
|---|---|
| [`technical_report.md`](technical_report.md) | 기술문서: 방향 전환 배경, 모델별 설계와 결과, 융합 계층, 인용 문헌, 확장 로드맵, 재현 방법 |
| [`model1_rul/`](model1_rul/) | 모델 1 학습 노트북, 평가 지표(`metrics.json`), 윈도우 단위 예측값(`predictions.npz`) |
| [`model2_diagnosis/`](model2_diagnosis/) | 모델 2 학습 노트북, 평가 지표(`metrics.json`), 미지 고장유형 지표(`metrics_unseen_fault_types.json`), 모델 1 연동 파라미터(`fusion_interface.json`), 비행 단위 예측값(`predictions.npz`) |
| [`ui_mockup/`](ui_mockup/) | 화면 목업 2종: 34대 위험도 대시보드, 엔진 상세(생존곡선과 베이즈 갱신) |

## 핵심 결과

| 모델 | 데이터 | 결과 |
|---|---|---|
| 모델 1: 잔여수명 확률예측 | N-CMAPSS 엔진 34대, 엔진 단위 교차검증 | 90% 구간 커버리지 0.902, 권고 시점 위반율 0.119 (엔진별 보정 시 0.025, 목표 0.10 이하), 정책 시뮬레이션 0대 고장 |
| 모델 2: 정비 필요 시점 예측 | NGAFID 28,935편 중 20,207편, 정비 사건 단위 교차검증 | 정확도 0.762, AUC 0.849 (초기 이진 모델 0.74 / 0.76) |
| 융합 | 모델 1 + 모델 2 | 경보 시 엔진별 보정 운영점 적용(임계 5에서 34대 전부 고장 전 정비), 경보 우도비 2.21 |

## 재현

각 노트북을 Google Colab GPU 런타임에서 위에서부터 실행합니다. 모델 1은 Google Drive에 N-CMAPSS h5 파일이 필요하고, 모델 2는 NGAFID 데이터를 자동으로 내려받습니다. 저장된 `predictions.npz`가 있으면 재학습 없이 정책 시뮬레이션과 융합 부분만 재현할 수 있습니다. 자세한 절차는 [기술문서 7절](technical_report.md#7-재현-가이드)을 참고하세요.
